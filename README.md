# 👗 Fashion Retail Sales Analysis Dashboard

## 📊 Project Overview

This project presents an interactive **Fashion Retail Sales Analysis Dashboard** built with **Power BI** to analyze sales performance, customer behavior, product performance, and payment methods.

The dashboard transforms retail sales data into meaningful business insights through interactive visualizations and KPIs.

---

## 🎯 Project Objectives

* Analyze overall fashion retail sales performance.
* Identify top-performing products.
* Analyze sales by product category.
* Understand customer purchasing behavior.
* Analyze sales by payment method.
* Track sales performance over time.
* Identify the best-performing locations.
* Provide actionable business insights using Power BI.

---

## 🛠️ Tools & Technologies

* **Power BI** – Dashboard development and data visualization
* **Microsoft Excel** – Data source
* **Power Query** – Data cleaning and transformation
* **DAX** – Measures and KPI calculations
* **GitHub** – Project documentation and version control

---

## 📌 Dashboard Pages

### 🏠 Sales Overview

Provides a complete overview of the retail business performance.

**Key KPIs:**

* Total Sales
* Total Revenue
* Total Quantity Sold
* Average Sales
* Number of Transactions

---

### 👕 Product Analysis

Analyzes product performance across the fashion retail business.

Includes:

* Top-selling products
* Sales by product category
* Quantity sold
* Product performance
* Revenue contribution

---

### 👥 Customer Analysis

Provides insights into customer purchasing behavior.

Includes:

* Customer sales performance
* Number of transactions
* Customer purchasing patterns
* Top customers

---

### 💳 Payment Analysis

Analyzes the distribution of sales across different payment methods.

Includes:

* Sales by payment method
* Transaction count
* Payment method contribution

---

### 📍 Location Analysis

Analyzes sales performance across different locations.

Includes:

* Sales by location
* Revenue by location
* Top-performing locations
* Geographic sales performance

---

## 📈 Key KPIs

| KPI            | Description                         |
| -------------- | ----------------------------------- |
| Total Sales    | Total sales generated               |
| Total Revenue  | Total revenue generated             |
| Total Quantity | Total number of items sold          |
| Transactions   | Total number of transactions        |
| Average Sales  | Average value of sales transactions |

---

## 🔄 Data Preparation

The dataset was cleaned and prepared using **Power Query**.

Main steps included:

1. Removing unnecessary columns.
2. Handling missing values.
3. Removing duplicate records.
4. Correcting data types.
5. Transforming and formatting the data.
6. Creating calculated columns where required.
7. Creating DAX measures for dashboard KPIs.
